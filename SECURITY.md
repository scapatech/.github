# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any Scapa Technologies repository, please report it by opening a private security advisory on the relevant GitHub repository:

1. Go to the repository's **Security** tab
2. Click **Advisories** then **Report a vulnerability**
3. Provide a clear description of the issue and steps to reproduce

Please do not report security vulnerabilities through public GitHub issues.

## Response

Reports will be reviewed on a best-effort basis. As this is community-maintained software from a closed company, there is no SLA for fixes.
